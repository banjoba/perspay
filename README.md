# perspay · дневник кормления Персика

Одностраничное PWA для iPhone: большая лапка «покормить», таймер с тремя порогами
(2 ч · 3 ч · 4 ч), дневник по дням и календарь, стикерпак Персика на каждое состояние.
Без бэкенда: все данные лежат в `localStorage` на телефоне, работает офлайн.

## Запуск локально

```bash
python3 -m http.server 8787
```

Открыть `http://localhost:8787`. Сервис-воркер кэширует всё после первого визита,
поэтому при правках файлов обновляйте `VERSION` в `sw.js` или сбрасывайте кэш в DevTools.

## Установка на iPhone

Приложение опубликовано на GitHub Pages: **https://banjoba.github.io/perspay/**

1. Открыть адрес в Safari на телефоне.
2. Поделиться → «На экран “Домой”». Приложение откроется без браузерного интерфейса,
   со своей иконкой и в портретной ориентации.

Деплой: пуш в `main` автоматически обновляет сайт через минуту-две. После правок
кода нужно поднять `VERSION` в `sw.js`, иначе установленное приложение подхватит
новую версию только со второго открытия.

## Правила

| Прошло с кормления | Состояние | Что происходит |
| --- | --- | --- |
| до 2 ч | Сытый | Лапка серая, нажатие вызывает Хитреца и не записывается |
| 2–3 ч | Можно | Кормить можно, кольцо персиковое |
| 3–4 ч | Пора | Персик просит, кольцо янтарное |
| 4–5 ч | Срочно | Обморок, кольцо красное и пульсирует |
| 5–6 ч | Критично | Протест с плакатом |
| 6 ч + | Шок | Персик всё запомнил |

Пороги и тихие часы меняются на вкладке «Персик». Ночью (по умолчанию 00:00–07:00)
показывается спящий Персик, но разрывы считаются как обычно.

## Структура

```
index.html            разметка трёх экранов и таб-бар
css/app.css           кремовая палитра, тёмная тема, safe-area
js/app.js             вкладки, тик каждые 30 с, регистрация SW
js/store.js           состояние + localStorage
js/feeding.js         чистая логика: фазы, разрывы, качество дня, форматирование
js/status.js          сводный статус для главного экрана
js/phrases.js         стикеры и реплики Персика
js/views/*.js         экраны «Сегодня», «Дневник», «Персик»
js/sheets/*.js        шторка добавления и редактирования записи
js/components/*.js    шторка, тост, конфетти
stickers/*.webp       стикеры для интерфейса (640 px)
stickerpack/*.png     стикеры для Telegram/VK (512 px, прозрачный фон)
tools/process_stickers.py  обрезка, ресайз и сборка иконок из сырых генераций
```

## Данные

Экспорт и импорт JSON на вкладке «Персик». Формат:

```json
{ "feedings": [{ "id": "…", "at": 1760000000000, "note": "курица" }], "settings": { "minGapMin": 120 } }
```
