# perspay · дневник кормления Персика

Одностраничное PWA для iPhone: большая лапка «покормить», таймер с тремя порогами
(2 ч · 3 ч · 4 ч), дневник по дням и календарь, стикерпак Персика на каждое состояние.
Без бэкенда: все данные лежат в `localStorage` на телефоне, работает офлайн.

## Запуск локально

```bash
python3 tools/serve.py 8787
```

Открыть `http://localhost:8787`. Сервер отдаёт файлы без HTTP-кэша. Сервис-воркер
работает по принципу cache-first с атомарными версиями: при правках поднимайте `VERSION`
в `sw.js` (и `APP_VERSION` в `js/app.js`), иначе страница продолжит жить на старом наборе файлов.

## Установка на iPhone

Приложение опубликовано на GitHub Pages: **https://banjoba.github.io/perspay/**

1. Открыть адрес в Safari на телефоне.
2. Поделиться → «На экран “Домой”». Приложение откроется без браузерного интерфейса,
   со своей иконкой и в портретной ориентации.

Деплой: пуш в `main` автоматически обновляет сайт через минуту-две. После правок
кода нужно поднять `VERSION` в `sw.js` и `APP_VERSION` в `js/app.js`: установленное
приложение скачает новый набор файлов целиком и перезагрузится само при следующем открытии.

## Правила

| Прошло с кормления | Состояние | Что происходит |
| --- | --- | --- |
| до 2 ч | Сытый | Лапка серая, нажатие вызывает Хитреца и не записывается |
| 2–3 ч | Можно | Кормить можно, кольцо персиковое |
| 3–4 ч | Пора | Персик просит, кольцо янтарное |
| 4–5 ч | Срочно | Обморок, кольцо красное и пульсирует |
| 5–6 ч | Критично | Протест с плакатом |
| 6 ч + | Шок | Персик всё запомнил |

Пороги и тихие часы меняются на вкладке «Персик». Ночью (по умолчанию 00:00–07:00)
показывается спящий Персик, но разрывы считаются как обычно.

## Виджет на экране iPhone

PWA не умеет виджеты, поэтому виджет живёт в бесплатном приложении **Scriptable**
и читает записи с крошечного эндпоинта синхронизации.

1. В приложении: вкладка «Персик» → «Виджет на экране» → включить синхронизацию.
2. «Как поставить виджет» → «Скопировать скрипт» (код синхронизации уже вшит).
3. В Scriptable: «+» → вставить → назвать «Персик».
4. На экране «Домой» добавить виджет Scriptable, в его настройках выбрать скрипт «Персик».

Виджет показывает стикер, статус, живой таймер с последнего кормления и ближайшее окно.
Размеры: маленький, средний, прямоугольный на экране блокировки. Обновляется каждые
10–15 минут, при отсутствии сети берёт последние данные из кэша.

Тап по виджету открывает Scriptable с вопросом «Покормить Персика?». Подтверждение шлёт
`POST /persik/<код>/feed`: сервер проверяет минимальный интервал из настроек и дописывает
кормление с пометкой «с виджета». Приложение подтягивает серверные записи (merge) при
каждом открытии и возврате на передний план, поэтому запись появляется в дневнике сама.

Кнопка «Открыть дневник» запускает команду «Персик» из «Быстрых команд» (iOS не открывает
установленное веб-приложение по https-ссылке). Команда создаётся вручную: одно действие
«Открыть приложение» → «Персик». Имя задаётся в стабе константой `OPEN_SHORTCUT`.

Стаб-скрипт при каждом запуске подтягивает свежий `widget/persik-widget.js` с этого сайта
и кэширует его, поэтому обновления виджета выкатываются обычным пушем.

### Эндпоинт синхронизации

`server/persik_sync.py` + `server/persik-sync.service`: stdlib-сервер на `127.0.0.1:8890`,
за Caddy по пути `https://185-173-144-167.sslip.io/persik/<код>`. `GET` отдаёт JSON,
`PUT`/`POST` сохраняет его в `/var/lib/persik-sync/<код>.json`, `POST …/feed` дописывает
кормление «сейчас» с проверкой минимального интервала (ответ `{ok, message}`). Код синхронизации
(32 hex-символа) одновременно идентификатор и секрет. CORS открыт только для
`https://banjoba.github.io`.

Деплой: `scp server/persik_sync.py root@185.173.144.167:/opt/persik-sync/ && ssh … systemctl restart persik-sync`.

## Структура

```
index.html            разметка трёх экранов и таб-бар
css/app.css           кремовая палитра, тёмная тема, safe-area
js/app.js             вкладки, тик каждые 30 с, регистрация SW
js/store.js           состояние + localStorage
js/feeding.js         чистая логика: фазы, разрывы, качество дня, форматирование
js/status.js          сводный статус для главного экрана
js/phrases.js         стикеры и реплики Персика
js/sync.js            синхронизация с эндпоинтом для виджета
widget/persik-widget.js  код виджета Scriptable
server/               эндпоинт синхронизации и systemd-юнит
js/views/*.js         экраны «Сегодня», «Дневник», «Персик»
js/sheets/*.js        шторка добавления и редактирования записи
js/components/*.js    шторка, тост, конфетти
stickers/*.webp       стикеры для интерфейса (640 px)
stickerpack/*.png     стикеры для Telegram/VK (512 px, прозрачный фон)
tools/process_stickers.py  обрезка, ресайз и сборка иконок из сырых генераций
```

## Данные

Экспорт и импорт JSON на вкладке «Персик». Формат:

```json
{ "feedings": [{ "id": "…", "at": 1760000000000, "note": "курица" }], "settings": { "minGapMin": 120 } }
```
